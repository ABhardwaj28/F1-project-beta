# 🏎️ F1 Analysis Test

My first small experiment with **Formula 1 data analysis** using Python.

This repository was created to learn the basics of working with F1 datasets, extracting useful information, and visualizing race data.

## 🛠️ Tech Used

- Python
- FastF1
- Pandas
- Matplotlib

## 📊 What I Explored

- Loading F1 session data
- Basic driver and lap analysis
- Comparing lap times
- Creating simple visualizations
- Getting familiar with the FastF1 library

## 🚀 Purpose

This was my **first F1 data-analysis project** and served as a starting point for learning how telemetry and race data can be analyzed programmatically.

It eventually led to the development of my larger **F1 Telemetry & Analysis Dashboard**.
